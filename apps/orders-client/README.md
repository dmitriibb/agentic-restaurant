# orders-client

Bootstrap React client for authentication, menu, basket, and order workflows.

## Environment

Create `.env` from `.env.example` when overriding local defaults.

## Local Run

1. Install dependencies:
   - `npm install`
2. Start dev server:
   - `npm run dev`
3. Run tests:
   - `npm test`
4. Build for production:
   - `npm run build`

Default dev URL: `http://localhost:5173`
