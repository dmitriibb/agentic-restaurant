# Done Archive

Completed tasks and their artifacts are moved here by task id.

Example:

- `agent/done/task-001/task-001.md`
- `agent/done/task-001/task-001.agents-audit.md`
- `agent/done/task-001/task-001.arch.md` (only when architecture was explicitly requested)
- `agent/done/task-001/task-001.plan.md`
- `agent/done/task-001/task-001.coder.md`
- `agent/done/task-001/task-001.test.md`
- `agent/done/task-001/task-001.review.md`
