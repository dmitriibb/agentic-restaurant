# Done Archive

Completed tasks and their artifacts are moved here by task id.

Example:

- `agent/done/task-001/task-001.md`
- `agent/done/task-001/task-001.agents-audit.md`
- `agent/done/task-001/task-001.arch.md` (only for architecture tasks)
- `agent/done/task-001/task-001.split.md` (only for architecture tasks)
- `agent/done/task-001/task-001.plan.md` (only for implementation tasks)
- `agent/done/task-001/task-001.coder.md` (only for implementation tasks)
- `agent/done/task-001/task-001.test.md` (only for implementation tasks)
- `agent/done/task-001/task-001.review.md` (only for implementation tasks)

Implementation tasks that were generated from an architecture task should reference that archived architecture through `source_architecture`.
